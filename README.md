# 重説用物件調査ツール Ver.1

不動産売買仲介業務で、重要事項説明書を作成する前の物件調査チェックリストを管理するためのシンプルなWebアプリです。

Reactなどのフレームワークは使わず、HTML・CSS・JavaScriptのみで作成しています。

## バージョン状態

現在の状態は Ver.1.0候補です。

PC表示に加えて、スマホ表示にも対応しています。画面幅が狭い場合は、チェックリストが横スクロールなしの縦積み表示になります。

## ファイル構成

```text
index.html
style.css
app.js
checklistData.js
README.md
```

## 使い方

1. `index.html` をブラウザで開きます。
2. 画面上部の物件情報を入力します。
3. 各チェック項目の状態、メモ、重説反映チェックを入力します。
4. 画面下部の一覧に、未確認項目、確認中項目、重説反映チェック済項目が自動表示されます。

入力内容はブラウザのローカルストレージに保存されます。同じブラウザで再度開くと、前回の入力内容が復元されます。

## 実装している機能

## チェック項目を編集する方法

チェック項目は `checklistData.js` にまとめています。

項目を追加したい場合は、対象カテゴリの `items` に次のような形式で追加してください。

```javascript
{
  name: "追加したい項目名",
  hint: "確認する内容のメモ"
}
```

## JSONバックアップ・インポート

保存データの最上位に `schemaVersion: 2` を保存します。schemaVersionがない旧形式とschemaVersion 1のデータも読み込めます。

保存データは従来どおり `jusetsuResearchToolV1` というlocalStorageキーに保存されます。所在地、地番、物件種別、チェック状態、メモ、重説反映チェックの構造は変更していません。

画面下部のバックアップセクションから、現在の保存データをJSONファイルとしてエクスポートできます。ファイル名は `bukken-chosa-backup-YYYYMMDD-HHMM.json` 形式です。

JSONインポートでは、選択したバックアップデータで現在の入力内容を上書きします。インポート前に確認メッセージが表示されます。

schemaVersionがない旧形式のJSONとschemaVersion 1のJSONも読み込めます。不足している項目は初期値で補完されます。

壊れたJSON、propertyまたはitemsがないJSON、未対応のschemaVersionのJSONは読み込まず、現在の保存データを維持します。
## 価格査定入力データ

将来の土地価格査定機能に備えて、保存データの最上位に `valuation` を追加しました。schemaVersionは `2` です。

既存の `property` と `items` の構造は変更していません。schemaVersionがない旧形式、またはschemaVersion 1のデータを読み込んだ場合は、既存の物件情報とチェック状態を維持したまま `valuation` を初期値で補完します。

価格査定画面は土地のみ対応です。物件種別が戸建またはマンションの場合は、土地のみ対応の案内を表示します。

保存される主な査定入力は以下です。

- 土地面積㎡、土地面積坪
- 路線価数値、路線価記号、路線価年度、路線価倍率、路線価メモ
- 初期想定坪単価、自動提案前の参考坪単価、初期想定単価の根拠
- 個別補正の適用有無、補正率、理由メモ
- 早期売却係数、売出提案係数、丸め単位
- 算出根拠メモ、査定日、最終保存日時

JSONエクスポートには `valuation` も含まれます。schemaVersion 1以前のJSONをインポートした場合も、`valuation` は初期値で補完されます。

現時点では、㎡と坪の自動換算、路線価計算、補正率合計、査定価格計算、根拠文の自動生成は行いません。入力値の保存と復元のみです。

## Phase 1C-2 土地査定計算

Phase 1C-2として、土地の価格査定画面に概算計算を追加しました。計算処理は `valuationEngine.js` に集約し、`app.js` から呼び出しています。schemaVersionは2のままです。

### 実装した計算

- ㎡から坪、坪から㎡への自動換算
- 路線価参考㎡単価 = 路線価数値（千円／㎡） × 1,000 × 路線価倍率
- 路線価参考坪単価 = 路線価参考㎡単価 × 3.305785
- 路線価参考総額 = 路線価参考㎡単価 × 土地面積㎡
- 補正合計率 = 適用した個別補正率の単純合計
- 補正後坪単価 = 初期想定坪単価 ×（1 + 補正合計率 ÷ 100）
- 基準価格 = 初期想定坪単価 × 土地面積坪
- 査定中心価格 = 補正後坪単価 × 土地面積坪
- 早期売却価格 = 査定中心価格 × 早期売却係数
- 売出提案価格 = 査定中心価格 × 売出提案係数
- 指定した丸め単位での四捨五入
- 算出根拠文の定型生成

### 入力単位

- 初期想定坪単価は「万円／坪」で入力します。
- 路線価は「千円／㎡」で入力します。
- 個別補正率は「％」で入力します。
- 早期売却係数の入力範囲は0.70〜1.00です。
- 売出提案係数の入力範囲は1.00〜1.30です。
- 丸め単位は1万円、10万円、50万円、100万円から選択します。
- 内部の価格計算は円単位で行い、画面表示は主に万円単位で表示します。

### 注意事項

本機能による査定価格は、入力された路線価、初期想定単価および個別補正に基づく概算値です。実際の売却価格、成約価格、鑑定評価額を保証するものではありません。最終的な査定判断は、現地状況、取引事例、市場動向、法令上の制限等を確認したうえで行ってください。

地域相場マスター、過去査定データ、中央値・平均値による自動提案、CSV、PDF、外部API、AI査定は未実装です。
