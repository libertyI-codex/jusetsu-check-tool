# 重説用物件調査ツール Ver.1

不動産売買仲介業務で、重要事項説明書を作成する前の物件調査チェックリストを管理するためのシンプルなWebアプリです。

Reactなどのフレームワークは使わず、HTML・CSS・JavaScriptのみで作成しています。

## バージョン状態

現在の状態は Ver.1.0候補です。

PC表示に加えて、スマホ表示にも対応しています。画面幅が狭い場合は、チェックリストが横スクロールなしの縦積み表示になります。

## ファイル構成

```text
index.html
style.css
app.js
checklistData.js
README.md
```

## 使い方

1. `index.html` をブラウザで開きます。
2. 画面上部の物件情報を入力します。
3. 各チェック項目の状態、メモ、重説反映チェックを入力します。
4. 画面下部の一覧に、未確認項目、確認中項目、重説反映チェック済項目が自動表示されます。

入力内容はブラウザのローカルストレージに保存されます。同じブラウザで再度開くと、前回の入力内容が復元されます。

## 実装している機能

- 物件情報の入力
- 物件種別の選択
- カテゴリ別チェックリスト表示
- 状態管理（未確認・確認中・確認済・対象外）
- メモ入力
- 重説反映チェック
- 下部一覧の自動更新
- 入力内容の保存とリセット

## 今回実装していない機能

- 外部サイト連携
- ハザード自動取得
- 登記自動取得
- 地図表示
- AIによる法的判断
- 重説自動作成
- PDF出力
- 印刷画面

## チェック項目を編集する方法

チェック項目は `checklistData.js` にまとめています。

項目を追加したい場合は、対象カテゴリの `items` に次のような形式で追加してください。

```javascript
{
  name: "追加したい項目名",
  hint: "確認する内容のメモ"
}
```

## 他のPCで使う方法

1. ZIPファイルを解凍します。
2. 解凍したフォルダ内の index.html を開きます。
3. Chrome または Edge で開くことを推奨します。
4. 入力内容は、開いた端末のブラウザ内に保存されます。
5. 他の端末とは入力内容が自動共有されません。
6. 会社PCで使用する場合は、社内ルールに従ってください。

## スマホで使う方法のメモ

スマホで使うには、GitHub Pages、Netlify、Cloudflare Pages などの静的サイト公開サービスを利用する方法があります。

Web公開しても、入力データは各端末のブラウザに保存されます。

端末間で案件データを共有するには、将来的にクラウド保存機能が必要です。
